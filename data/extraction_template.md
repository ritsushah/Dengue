## Instructions for Data Extractors

1. **Pilot extraction:** Both reviewers will independently extract data from the first 3 included studies, compare results, and resolve discrepancies to calibrate the extraction process before proceeding.
2. **2×2 table reconstruction:** If TP, FP, FN, TN are not directly reported, reconstruct from sensitivity, specificity, and total sample size using:
   - TP = Sensitivity × Number of true positives by reference standard
   - FN = (1 − Sensitivity) × Number of true positives by reference standard
   - TN = Specificity × Number of true negatives by reference standard
   - FP = (1 − Specificity) × Number of true negatives by reference standard
3. **Zero-cell handling:** If any cell = 0, flag with an asterisk (*). A continuity correction of 0.5 will be applied to all four cells during statistical analysis.
4. **Missing data:** Record as "NR" (Not Reported). Do not impute values. Contact corresponding authors for missing 2×2 data if feasible.
5. **Multiple 2×2 tables per study:** If a study reports separate 2×2 data by subgroup (e.g., by serotype, infection status, or fever day), extract each subgroup table in a separate row and note the subgroup in the "Notes" column.
